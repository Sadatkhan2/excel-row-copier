Excel Row Copier

Pick rows from one Excel sheet by serial number and append them to another. Files stay in your browser.

1Source file

Click or drop the Excel file to copy rows from

2Destination file

Click or drop the Excel file to paste rows into

3Choose rows

Use commas and ranges. "Row position" counts data rows below the header (1 = first data row).

4Get the result

Rows are appended after the last row of the destination sheet. Other sheets are kept. Cell colours and fonts may not carry over (values and formulas' results do).
